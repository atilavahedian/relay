The problem

You became the clipboard.

Every second opinion means copying code out of one agent, pasting it into another, and pasting the answer back. Context gets lost every time.

Before

  1. Copy the diff from Claude
  2. Paste it into Codex, explain the project again
  3. Copy Codex's answer
  4. Paste it back into Claude
  5. Repeat for every follow-up

With relay

  1. Say “ask codex to review this”

How it works

One command. Then just ask.

Install

relay finds every agent on your machine and connects them.

relay init

Ask in plain words

From inside any agent, name another one and say what you want.

"hand the tests to codex"

Get the answer back

The other agent works in the same repo and its reply lands in your conversation.

codex replied after 41s…

Why it works

Built to disappear.

Your existing logins

relay runs the real CLIs, so there are no API keys and no extra bills.

Context attached

Branch, changed files, the diff and recent history go along automatically.

Agents remember

Follow-ups to the same agent continue its previous session.

Full-power agents

The agent receiving the task keeps its own tools, sandbox and repo access.

No loops

An agent started by relay can't hand work back again.

Tiny and local

Zero dependencies. Everything stays on your machine in ~/.relay.
